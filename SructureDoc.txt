Explications clés

    backend/app/main.py : Lance FastAPI et inclut les routes via include_router.

    models/ : Définition des tables SQLAlchemy.

    schemas/ : Validation des données entrantes et sortantes avec Pydantic.

    crud/ : Fonctions de gestion de la BDD, évite de mettre la logique dans les routes.

    api/ : Organisation des endpoints REST API par fonctionnalités.

    services/ : Logique métier comme la recommandation (cosine similarity), et scraping (Selenium).

    core/ : Config globale, sécurité, gestion des dépendances FastAPI.

    frontend/ : Tout le côté client en HTML/CSS + JS, séparé du backend.

    scraping/ : Scripts dédiés pour extraire les livres de books.toscrape.com avec Selenium.

Tech & bonnes pratiques

    Utiliser async def dans FastAPI pour les appels I/O (DB, scraping).

    Gestion propre des sessions DB avec dépendances FastAPI.

    Sécurité avec JWT et mots de passe hachés (bcrypt).

    Validation forte côté backend avec Pydantic.

    Frontend responsive avec Tailwind ou Bootstrap.

    Modularité claire pour faciliter la maintenance et les tests.

    Tests automatisés dans /tests.
